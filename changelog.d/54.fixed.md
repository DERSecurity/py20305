**An event superseded for only some of its modes now releases the rest when it
ends (#54).** A device goes into the event's superseded set when another event
takes over any one of its modes there, and the end-of-event pass left out every
such device. The modes the other event never took stayed on the device, and the
registration saying the event still owned them outlived it, so the next event to
release the same mode read it as still covered and left it alone too. A device
is now left out only when every mode the event owns there was superseded, which
keeps the superseding event's own activation as the write that moves a device
taken over entirely.
