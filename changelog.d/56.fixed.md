**A DefaultDERControl is no longer written over a mode another event is still
controlling (#56).** Two events can hold the same device for different modes
without either superseding the other. When one ended, the default that came
back was written whole, so a mode the default named and the other event was
running was taken from the event that owned it. The default is now withheld on
that device when it names a mode another active event holds, and the ending
event's own modes are disabled instead; the event still running keeps what is
its, and its own end brings the default back for everything at once. Where the
default names nothing the other event is running it is applied as before:
sharing a device is not on its own a reason to withhold it.
