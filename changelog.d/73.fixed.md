**Discovery reads every page of the DER lists (#73).** A list GET without `l` returns one entry (IEEE 2030.5 GEN.019), and discovery read the DERList with a plain GET, so a server that lists more than one DER, as a 2018 server may, had its later DERs missed. Discovery now pages the DERList with `s` and `l`, and the SubscriptionList read for its `pollRate` asks for one entry explicitly.
