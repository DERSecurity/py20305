**The SunSpec connector reports the state of charge (#111).** `SunSpecModbusConnector.fetch_monitoring()` adds `SoC`, in percent, from the first of model 713 `SoC`, model 124 `ChaState` and model 802 `SoC` that the device has and populates, and otherwise from model 713 `WHAvail` over `WHRtg`. Model 124 and model 802 are read only when no earlier source gave a value, and a failed read of either is skipped for the same interval as model 713. `SunSpecConnector.fetch_status()` reports the same value as DERStatus `stateOfChargeStatus`, in hundredths of a percent.
