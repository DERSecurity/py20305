**A host application can split one client's EndDevices between processes (#114).** Four optional parameters, each off by default: `CsipClient(device_filter=...)` (a callable, or a `DeviceSet` of hrefs and LFDIs) limits the EndDevices a process discovers, acts for and responds for, and a process with a filter never cancels a subscription another process may need; `CsipClient(own_end_device=False)` leaves the client's own-EndDevice work (subscription renewal, reconciliation and cancellation, EndDevice registration and re-registration, telemetry for the client's own LFDI) to another process; `NotificationServer(forward=...)` hands each notification's body to the host and answers 201 only after the host has taken it, 503 if it could not, and `CsipClient.process_notification()` acts on it in the process that reads it; `CsipClient(request_limiter=...)` is awaited before every request to the server, so processes can share one request budget.
