**EndDevices can move from one client process to another without a repeated Response or control (#115).** With `CsipClient(event_state_store=...)` the event processor saves a snapshot of each EndDevice's events, randomized timing, applied default and loss-of-communications boundary to a shared `EventStateStore`, and records each Response as it is posted. `release_devices()` hands devices over without posting or writing anything; `take_over_devices()` loads their state, rediscovers, carries each event on with its timing, and applies a running event only to a device that never received it. Event randomization offsets are shared through the store, so an event acting on devices of several processes has one start and end. Without a store nothing changes.
