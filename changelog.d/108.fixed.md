**An unreachable or unresponsive server no longer holds a client's shutdown for 15 to 30 s (#108).**
`CsipClient.shutdown()` waited for every subscription DELETE without a bound, so a server
that accepted the connection and never answered held it for the HTTP read timeout (15 s),
and one that could not be reached for every connection attempt and retry. The DELETEs now
get 2 s in all (`subscription_cancel_timeout`, `None` for the old behavior), and one
still unanswered is abandoned. `NotificationServer.stop()` likewise waits at most 2 s
(`shutdown_timeout`) for a notification still being received, where aiohttp's default
held it for 60 s.
