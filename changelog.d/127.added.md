**`Sep2Client.seconds_since_contact()` and `get_list(..., absent_as_empty=False)` (#127).** `seconds_since_contact()` returns the seconds since the last reachable round-trip on the monotonic clock, or `None` before the first. `get_list` with `absent_as_empty=False` raises the new `Sep2ListNotFoundError` (a `Sep2ProtocolError` with status 404) for a first-page 404 instead of returning an empty list, for a caller that must tell a list the server does not serve from an empty one.
