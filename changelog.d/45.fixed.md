**Meter readings are posted at the postRate the server returns on the MirrorUsagePoint
(#45).** The rate was read back after the MUP POST but never reached the posting loop or
the device read cadence, so both stayed at the EndDevice or configured rate (300 s by
default), and a rediscovery reset the stored rate as well. Both now follow the server's
rate. A postRate of 0 is ignored, and a failed readback is logged as a warning.

**The Time resource is polled at its own pollRate, and server poll rates are no longer
capped at 7200 s (#45).** The Time poll used the DeviceCapability rate, and every
server-advertised pollRate above two hours was cut to 7200 s, so a server asking for a
daily Time poll was polled 12 times as often. Time now follows its own pollRate, the
shortest per-FSA Time rate when there is no global Time resource, and the DeviceCapability
rate only when no Time resource could be read. The 10 s lower bound is unchanged. The
connectivity heartbeat, which also GETs Time, is unaffected.
