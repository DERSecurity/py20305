**A DefaultDERControl now sets the modes no active event controls, including on a device that has an event running (#100).** IEEE 2030.5-2023 §10.10.4.2.1 manages each control mode by the default when no active DERControl holds it. The initial default pass used to leave out every device with an active event, so a default that arrived or changed during an event reached none of its modes until the event ended. It now sends each device the default without the modes the running events hold there, as the end-of-event fallback already does, and a default naming only held modes writes nothing. A default that names no control mode still waits for the device's events to end. This changes what the client writes to a device during an event. Closes #64.
